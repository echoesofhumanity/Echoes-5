# Echoes Academy — Zero-Cost Mandate V1

Date: 2026-10-26
Status: BINDING PROJECT CONSTRAINT / PLANNING ONLY

## Non-negotiable constraint
Academy must be built and operated at **zero monetary cost** until the founder explicitly authorizes spending after financing. No paid hosting, domains, dedicated conferencing servers, SaaS subscriptions, paid media storage, payment-card-dependent trials, licenses, or automatic overage billing. Do not provision infrastructure or open accounts without separate authorization.

## Evaluation criteria
- Prefer existing GitHub Pages public catalog and free/open-source tooling.
- Free software does not imply free hosting, storage, bandwidth, TURN servers, recording, or operations.
- Validate actual provider terms, limits, participant caps, recording, moderation, data privacy, accessibility and ability to embed; do not assume a third-party free tier is permanent or unlimited.
- Any capped free tier must have enforced limits or shutoff that prevents charges.
- Avoid placing real student records, authentication tokens or private educational materials in GitHub Pages.
- Keep an adapter boundary for future replacement by paid or self-hosted conferencing and LMS services.

## Revised staged approach
1. Continue Academy-owned offline synthetic tests and security contracts at no monetary cost.
2. Build static reading/notes/course previews and browser-only demo interactions on existing free hosting. For real media, assess storage/bandwidth limits and content licensing first.
3. Research no-charge live interactive class options (e.g. publicly hosted Jitsi or provider free plans) **without assuming guaranteed availability, embedding rights, recordings, SLA, or privacy**. A teacher can test external meeting links only after reviewing terms and safeguards; never publish open join links for minors.
4. Evaluate free LMS options with zero-cost operational reality: Moodle software is free, but reliable hosted Moodle is not automatically free. Prefer progressive Academy-owned front end and test-only backend until a sustainable free backend is proven.
5. Pilot with consenting adults, limited class size, no recording by default, moderated attendance and no sensitive personal data.
6. Revisit paid managed BigBlueButton, hosting and recording only when funding exists and spending is separately approved.

## Go/no-go gate
No live learner launch unless verified $0 recurring cost, sustainable quotas, privacy/consent, access control, moderation, safeguarding, accessibility and operational reliability. If a requirement cannot be met at $0, defer that feature rather than create hidden costs.

## Protected systems
Do not touch Admin V3, archives, clones, backups, shared Supabase/auth/RLS, unrelated pages or blank header logo placeholder. This document does not authorize deployment or external account creation.
